# P6 — Gap Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the four gaps identified between the P4/P5 plans and the merged implementation: auto-migrate+seed on startup, authenticated run-now internal call, audit logging for all mutating webapi handlers, and a missing `audit_log.sql` query file.

**Architecture:** Three independent changes touch distinct layers. (1) `serve.go` bootstraps by calling `db.Migrate` + `CreateOrganization` before starting the API server. (2) `webapi/schedules.go` mints a short-lived bearer token via `token.Signer` (already in `Deps` for API, needs adding to `webapi.Deps`) and passes it as an `Authorization` header when calling the internal run-now endpoint. (3) All mutating webapi handlers call a shared `insertAuditLog` helper that writes to the `audit_log` table — the sqlc query file is added first so the generated code is available.

**Tech Stack:** Go 1.23, pgx/v5, sqlc (generated code — run `sqlc generate` after adding query file), goose (migrations already applied), `internal/token` (existing `*token.Signer`), `internal/api` internal endpoint (existing loopback-gated `POST /internal/schedules/{id}/run-now`).

```go
func (h *schedulesHandler) runNow(w http.ResponseWriter, r *http.Request) {
    idStr := r.PathValue("id")
    if _, err := uuid.Parse(idStr); err != nil {
        writeErr(w, http.StatusBadRequest, "invalid schedule id", "bad_request")
        return
    }
    claims := mustClaims(r)
    actor := claims.Login

    apiBase := h.deps.APIBaseURL
    if apiBase == "" {
        apiBase = "http://127.0.0.1:8080"
    }
    url := apiBase + "/internal/schedules/" + idStr + "/run-now"

    body, _ := json.Marshal(map[string]string{"actor": actor})
    req, err := http.NewRequestWithContext(r.Context(), "POST", url, bytes.NewReader(body))
    if err != nil {
        writeErr(w, http.StatusInternalServerError, "failed to build request", "internal")
        return
    }
    req.Header.Set("Content-Type", "application/json")

    if h.deps.Signer != nil {
        tok, _, err := h.deps.Signer.Sign(token.RunClaims{
            RunID:     uuid.New(),
            OrgID:     uuid.New(),
            ExpiresAt: time.Now().Add(30 * time.Second),
        })
        if err != nil {
            writeErr(w, http.StatusInternalServerError, "failed to mint token", "internal")
            return
        }
        req.Header.Set("Authorization", "Bearer "+tok)
    }

    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        writeErr(w, http.StatusBadGateway, "trigger call failed", "gateway")
        return
    }
    defer resp.Body.Close()
    if resp.StatusCode >= 400 {
        writeErr(w, resp.StatusCode, "trigger failed", "trigger_error")
        return
    }
    w.WriteHeader(http.StatusAccepted)
}
```

```go
package webapi

import (
    "context"

    "github.com/jackc/pgx/v5/pgtype"

    dbgen "github.com/gambtho/cronfoundry/internal/db/gen"
)

// insertAuditLog writes one audit_log row. actor is the GitHub login from
// the session (may be empty for system actions). targetID may be a zero
// pgtype.UUID for actions where no specific resource ID is relevant.
func insertAuditLog(ctx context.Context, q *dbgen.Queries, orgID pgtype.UUID, actor, action, targetKind string, targetID pgtype.UUID) {
    // Fire-and-forget: audit failures must not break the primary action.
    _ = q.InsertAuditLog(ctx, dbgen.InsertAuditLogParams{
        OrgID:      orgID,
        Actor:      &actor,
        Action:     action,
        TargetKind: &targetKind,
        TargetID:   targetID,
    })
}

// InsertAuditLog is the exported form for use in tests.
func InsertAuditLog(ctx context.Context, q *dbgen.Queries, orgID pgtype.UUID, actor, action, targetKind string, targetID pgtype.UUID) error {
    return q.InsertAuditLog(ctx, dbgen.InsertAuditLogParams{
        OrgID:      orgID,
        Actor:      &actor,
        Action:     action,
        TargetKind: &targetKind,
        TargetID:   targetID,
    })
}
```
